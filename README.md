# praticas de Python - POO

Repositório destinado às práticas de Programação Orientada a Objetos (POO)
desenvolvidas após as aulas do curso de Python.

## Objetivo
Consolidar, por meio de exercícios práticos, os conceitos de POO estudados
no curso e registrar minha evolução no aprendizado de Python.

## Organização
Os exercícios propostos pelo curso são mantidos separadamente.

Este repositório contém apenas os desafios e práticas desenvolvidos como 
complemento aos conteúdos estudados.

  1. **pratica001.py** - Classes, objetos, atributos e métodos.
